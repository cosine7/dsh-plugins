# Task Center

为 DeepSeek Harness 桌面版提供持久化定时任务与跨会话任务管理。到期时准备执行会话，再把任务交给 Agent。

包名 `@cosine/dsh-task-center`，当前适配桌面版 DSH `0.2.1-rc.2`。可与官方 Schedule 插件同时使用，工具名称以 `task_center_` 开头。

## 能力

- 支持一次性、固定间隔、五字段 cron，以及按星期设置的多个时间窗口。
- 支持时区、起止日期、排除日期和触发时间预览。
- 在任意活动根会话中查看、修改、暂停、恢复和删除任务，并将任务转交给另一个会话。
- 复用指定会话，或每次触发创建新会话；指定目标已归档或不存在时自动创建替代会话。
- 可关联飞书通道，新建、替代或主动转交目标时一起转交订阅。
- 持久化任务与最近 500 条投递记录，使用 revision 防止并发覆盖。

## 安装与使用

按照[仓库安装说明](../../README.md#安装)链接本插件目录，重启桌面版 DSH 后即可在会话中提出需求：

- “每周一到周五，上海时区，上午9:31至11:30、下午13:01至15:00，每20分钟检查项目状态。”
- “每个月最后一天晚上8点整理总结，上海时区。”
- “列出任务中心全部任务，把周报任务转到当前会话。”
- “暂停这个任务 / 改成每30分钟 / 删除这个任务。”

插件自动注册 [dsh-task-center 操作手册](skills/dsh-task-center/SKILL.md)，供 Agent 读取，无需额外安装技能。目前没有独立管理面板。

## 会话与时间规则

任务目标分为两种模式：`session` 复用指定会话（默认当前会话），`new` 每次触发创建独立会话。插件不决定哪些任务应该共用会话，也不内置交易日、总结日或业务阶段。

指定目标未加载时，通过官方 Session Controller 恢复；已归档时保留归档状态，已删除或不存在时也不尝试恢复，均创建替代会话。首次替代消息附原 Session ID 与原因；归档历史可通过可用的会话搜索或读取工具查阅。替代成功后更新任务目标，后续触发复用它。读取失败、实例占用等异常不会被当成删除。

任务保存完整 prompt 和工作目录。新建会话采用宿主默认 Agent 配置，仅指定工作目录并投递普通任务消息，不覆盖或追加系统提示。目标忙时等待空闲；普通重试复用已准备的会话，避免反复创建。

DSH 未运行期间不执行任务。恢复后，周期任务合并逾期触发，仅投递最近一次；一次性任务保留到能够投递。暂停后主动恢复，从当前时间重新计算，不补跑暂停期间的任务。

转交只影响尚未投递的工作，已交给旧会话的消息不会撤回。投递记录中的 `delivered` 表示会话已接收，不代表 Agent 已完成业务。

创建任务时可用 `feishu_channel_ids` 选择源会话拥有的通道；省略继承源会话当前订阅，空数组表示不关联。订阅按所有者和 revision 校验后转交，用户后来主动改过的绑定不会被覆盖。若关联冲突，任务保留并记录错误，尚不投递；在目标会话调用 transfer 并明确 `rebind_feishu=true` 可重新关联其当前订阅。不会自动补投飞书的 unassigned 历史事件。

once/interval 可指定时区，默认保留输入时间的偏移；缺少时区的历史规则按宿主本地时区展示。windows 仅支持同一天内的窗口，不内置交易日历；夏令时空缺跳过、重复时间取较早一次。

## 退出、归档与数据

插件随 DSH 启动和卸载，不注册独立后台服务。任务与会话归档相互独立：归档不会暂停或删除任务，也不会因为未来任务阻止归档。只有显式暂停或删除任务才停止后续调度；投递结果不确定时仍会暂停，避免重复执行。

任务存储在 `$DSH_HOME/storages/cosine-task-center/tasks.json`，DSH_HOME 默认 `~/.dsh`。卸载或更换源码目录保留任务数据；同一任务库只允许一个 DSH 实例调度，最多保存 1000 个任务。

当前仅支持 version 2 数据结构。格式变更由维护者在 DSH 完全退出后备份并直接转换本机数据，不在插件启动时兼容或迁移旧格式。

投递过程中异常退出或持久化结果不确定时，相关任务会暂停。检查目标会话后再恢复，避免重复处理。任务存储与会话存储之间没有分布式事务，不能保证严格 exactly-once。

解除插件关联：

```powershell
& "$env:LOCALAPPDATA/Programs/DeepSeek Harness/resources/runtime/cli/bin/dsh.cmd" plugin --profile desktop remove @cosine/dsh-task-center
```

验证方法与历史记录见 [VALIDATION.md](VALIDATION.md)。
